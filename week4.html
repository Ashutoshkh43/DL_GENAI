2. The image-classification pipeline

Image classification means assigning an image to one label from a known set of classes. For example, an MNIST classifier maps a handwritten digit image to one of ten labels, 0 through 9.

A CNN classifier follows this broad computation:

Images and labels → CNN feature extraction → class scores (logits) → loss → parameter update
StageWhat it doesTypical object
Load and prepareRead images and labels; turn pixels into tensors and group examples into batches.Image tensor and integer class labels
Feature extractionConvolutional layers transform local image patterns into feature maps; activations and pooling can follow.Tensor shaped (N, C, H, W)
Classification headConvert the final features into one score per class.Logits shaped (N, K)
LearningCompare logits with correct labels, calculate loss, backpropagate gradients and update parameters.Scalar batch loss and updated weights
EvaluationMeasure predictions on held-out examples without updating parameters.Accuracy or another metric

Here N is batch size, C is channel count, H and W are image height and width, and K is number of classes. For RGB images, C = 3; a grayscale image has C = 1.

3. Images, labels and batches

3.1 Pixels become numbers

A grayscale image of height H and width W can be represented as H × W pixel values. A CNN library typically expects a batch with channel-first shape (N, C, H, W). For example, a batch of 32 grayscale 28 × 28 images has shape (32, 1, 28, 28).

A class label is commonly an integer in 0 through K-1. When labels are class indices for PyTorch's CrossEntropyLoss, their batch shape is (N,) and their dtype should be integer class-index type, normally torch.long.

3.2 Why use batches?

A batch is a group of examples processed together. Batching makes computation efficient and produces a gradient estimate from several samples at once. If there are 60,000 training examples and batch size is 64, one epoch contains about ceil(60000 / 64) = 938 batches; the last batch can be smaller.

3.3 A concrete MNIST batch

The official page names MNIST as one possible dataset example. The following is an independent PyTorch illustration of loading it; it is not a claim that this exact library or code appears in the course materials.

from torch.utils.data import DataLoader
from torchvision import datasets, transforms

transform = transforms.ToTensor()
train_data = datasets.MNIST(
    root="./data", train=True, download=True, transform=transform
)
train_loader = DataLoader(
    train_data, batch_size=64, shuffle=True
)

images, labels = next(iter(train_loader))
print(images.shape)  # torch.Size([64, 1, 28, 28])
print(labels.shape)  # torch.Size([64])
print(images.dtype)  # torch.float32
  • ToTensor() converts each image into a tensor and scales ordinary 8-bit pixel values to the range 0–1.
  • train=True selects the training split; download=True downloads the dataset if needed.
  • batch_size=64 asks the loader for groups of up to 64 samples.
  • shuffle=True changes the order of training examples each epoch.
  • The loader returns image batches and labels in matching order.

4. Supplementary worked model: a small CNN

This compact example uses two convolution and pooling stages followed by a linear classifier. It is chosen to make the image-to-logits path and dimensions explicit. It is a supplementary model, not a recovered Week 4 instructor architecture.

4.1 Layer-by-layer shape calculation

For a 2D convolution, the output height (and likewise width) is

\[H_{out}=\left\lfloor\frac{H_{in}+2P-D(K-1)-1}{S}+1\right\rfloor\]

Hin is input height, K kernel size, P padding, D dilation, and S stride. Here we use kernel 3, padding 1, dilation 1, stride 1; therefore height and width stay the same. A 2 × 2 max-pool with stride 2 halves each even spatial dimension.

OperationCalculationOutput shape
Input batch64 grayscale 28 × 28 images(64, 1, 28, 28)
Conv2d: 1 → 16 channels, 3 × 3, padding 1Spatial size preserved(64, 16, 28, 28)
MaxPool2d: 2 × 2, stride 228 ÷ 2 = 14(64, 16, 14, 14)
Conv2d: 16 → 32 channels, 3 × 3, padding 1Spatial size preserved(64, 32, 14, 14)
MaxPool2d: 2 × 2, stride 214 ÷ 2 = 7(64, 32, 7, 7)
Flatten each image32 × 7 × 7 = 1,568 features(64, 1568)
Linear classifierOne score for each of 10 digits(64, 10)

4.2 Model code and parameter counts

import torch
from torch import nn

class SmallCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2),
            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2),
        )
        self.classifier = nn.Linear(32 * 7 * 7, num_classes)

    def forward(self, x):
        x = self.features(x)       # (N, 32, 7, 7)
        x = torch.flatten(x, 1)    # (N, 1568); keep batch dimension
        return self.classifier(x)  # (N, num_classes), raw logits

model = SmallCNN()
sample = torch.zeros(4, 1, 28, 28)
print(model(sample).shape)  # torch.Size([4, 10])

nn.Conv2d(1, 16, ...) accepts one grayscale input channel and learns 16 filters. ReLU adds a nonlinear transformation. Pooling reduces the spatial dimensions. The second convolution learns 32 output channels from the 16 input channels. torch.flatten(x, 1) combines channel, height, and width dimensions while retaining batch dimension zero. The final linear layer produces ten raw scores, one per class.

With biases enabled, a convolution has (input channels × kernel height × kernel width + 1) × output channels parameters. The first convolution has (1×3×3+1)×16 = 160; the second has (16×3×3+1)×32 = 4,640. The classifier has (1,568+1)×10 = 15,690. Total: 20,490 trainable parameters.

Check before training: run one synthetic batch through the model and confirm the output is (N, 10). This catches many flattening and fully connected input-size mistakes before a full epoch.

5. Supplementary training loop

5.1 Logits, labels and cross-entropy

Logits are unnormalized class scores from the model. For multiclass classification, CrossEntropyLoss takes logits of shape (N, K) and integer class targets of shape (N,). It applies the needed log-softmax calculation internally, so do not add a softmax layer before this loss.

For one example with true class y and logits z, cross-entropy can be written as

\[\ell(z,y)=-\log\left(\frac{e^{z_y}}{\sum_{j=1}^{K}e^{z_j}}\right)\]

zj is the score for class j, zy is the true-class score, and K is the number of classes. Higher probability assigned to the true class means lower loss.

5.2 Complete training and evaluation example

import torch
from torch import nn
from torch.optim import Adam
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
transform = transforms.ToTensor()
train_data = datasets.MNIST("./data", train=True, download=True, transform=transform)
test_data = datasets.MNIST("./data", train=False, download=True, transform=transform)
train_loader = DataLoader(train_data, batch_size=64, shuffle=True)
test_loader = DataLoader(test_data, batch_size=256, shuffle=False)

model = SmallCNN().to(device)
loss_fn = nn.CrossEntropyLoss()
optimizer = Adam(model.parameters(), lr=1e-3)

for epoch in range(3):
    model.train()
    total_loss = 0.0
    total_seen = 0
    for images, labels in train_loader:
        images, labels = images.to(device), labels.to(device)
        optimizer.zero_grad()
        logits = model(images)
        loss = loss_fn(logits, labels)
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * labels.size(0)
        total_seen += labels.size(0)
    print(f"epoch {epoch + 1}: train loss {total_loss / total_seen:.4f}")

model.eval()
correct = 0
total = 0
with torch.no_grad():
    for images, labels in test_loader:
        images, labels = images.to(device), labels.to(device)
        logits = model(images)
        predictions = logits.argmax(dim=1)
        correct += (predictions == labels).sum().item()
        total += labels.size(0)
print(f"test accuracy: {correct / total:.2%}")

5.3 What each training step does

  1. model.train() selects training behavior for layers that distinguish train and evaluation modes.
  2. Move both images and labels to the same device as the model.
  3. optimizer.zero_grad() clears gradients left from the previous batch.
  4. The forward pass produces logits; the loss compares them with the correct labels.
  5. loss.backward() computes parameter gradients using backpropagation.
  6. optimizer.step() changes model parameters using those gradients.
  7. For reporting an epoch mean, multiply each mean batch loss by its sample count before summing, then divide by total samples. This handles a smaller final batch correctly.

The example runs three epochs for demonstration; that number is not a course prescription. Exact accuracy and loss depend on software versions, random initialization, hardware, and training settings, so no particular numerical result is promised here.

Evaluation: model.eval() changes layer behavior where relevant; torch.no_grad() prevents gradient storage. The test loader is not shuffled because stable order is convenient for evaluation. Evaluation must not call backward() or optimizer.step().

6. Reading predictions and evaluation

For logits shaped (N, K), argmax(dim=1) selects the largest-scoring class in each row, returning one predicted class index per image. Accuracy is the fraction of examples predicted correctly:

\[\text{accuracy}=\frac{\text{number of correct predictions}}{\text{number of evaluated examples}}\]

For example, 87 correct predictions among 100 images gives 87 / 100 = 0.87, or 87% accuracy. Accuracy is easy to read, but it does not show which classes are confused or whether errors are concentrated in a minority class. A confusion matrix can help inspect class-by-class mistakes.

7. Common mistakes and debugging checks

SymptomLikely causeCheck or fix
Conv2d expects 4D inputMissing batch or channel dimension.Print image shape; use (N,C,H,W). A single grayscale image needs (1,1,H,W) as a batch.
Expected 1 channel, got 3 (or vice versa)Model's first convolution does not match image channels.Set in_channels to the dataset channel count: 1 for grayscale or 3 for RGB.
Matrix multiplication shape error at LinearIncorrect flattened feature count.Trace each spatial operation and calculate C×H×W; test a dummy batch through the feature extractor.
CrossEntropyLoss target shape/type errorOne-hot targets or wrong dtype used for class-index loss.For this setup, use logits (N,K) and labels (N,) with integer class indices.
“Expected all tensors on same device”Model, images, or labels are on different devices.Move model, batch inputs, and targets to the same device.
Loss becomes NaN or training is unstablePossible non-finite inputs, overly aggressive learning rate, or numerical issue.Check torch.isfinite(images).all(), print loss and learning rate, and reduce learning rate if needed.
Evaluation unexpectedly changes weightsTraining code was reused during evaluation.Use model.eval() and torch.no_grad(); do not step the optimizer.

Useful debugging habit: print shapes at the boundaries between data, feature extractor, flatten operation, and classifier. Shape errors are easier to locate when the last correct shape is known.

8. Additional practice questions

These are newly written study questions based on the verified broad Week 4 image-classification scope and the supplementary example above. They are not taken from an official practice or graded assignment.

Question 1 — What is the output shape for a batch of 20 RGB images of size 32 × 32 entering Conv2d(3, 12, 3, padding=1)?
Answer: (20, 12, 32, 32). Batch size remains 20, output channels become 12, and kernel size 3 with padding 1 and stride 1 preserves height and width.
Question 2 — A batch contains 50 examples. What are the expected shapes for 10-class logits and integer class-index labels?
Answer: logits (50, 10), labels (50,). Each row of logits corresponds to one label.
Question 3 — The true class is 4. Why should a ten-class model return ten scores rather than applying argmax before the loss?
Answer: the loss needs all class scores to measure how probability mass is distributed and provide useful gradients. Argmax discards score magnitudes and is used after the forward pass for class prediction, not before cross-entropy training.
Question 4 — A model predicts 42 of 50 test images correctly. Calculate accuracy.
Worked answer: 42 / 50 = 0.84, so accuracy is 84%.
Question 5 — A flattened feature tensor has 1,568 values per image and the classifier has 10 output units. How many weights and biases does the linear layer have?
Worked answer: weights: 1,568 × 10 = 15,680. There is one bias per output unit, so 10 biases. Total: 15,690 parameters.
Question 6 — Name the correct evaluation changes to the training loop.
Answer: call model.eval(), evaluate inside torch.no_grad(), calculate predictions/metrics, and do not call loss.backward() or optimizer.step().
Question 7 — Debug: MNIST batches have shape (64, 1, 28, 28), but the model's first convolution is Conv2d(3, 16, 3). What is wrong?
Answer: the layer expects three channels while the batch has one grayscale channel. Set the first convolution's input channels to 1, or use a three-channel dataset/transform consistently.
