1. From forward passes to learning: the big picture

A neural network starts with inputs, applies a sequence of weighted transformations and activation functions, and produces a prediction. During training, the prediction is compared with the expected target. Backpropagation calculates how the parameters contributed to the error, and an optimizer uses the gradients to update them.

  1. Forward pass: calculate the prediction.
  2. Loss calculation: measure the difference between prediction and target.
  3. Backpropagation: calculate gradients using the chain rule.
  4. Optimization: update weights and biases.
  5. Repeat: train over batches and epochs.
  6. Validation: evaluate performance on data not used for parameter updates.
Keep the roles separate: the forward pass computes outputs, the loss measures error, backpropagation computes gradients, and the optimizer updates parameters.

2. Universal Approximation Theorem

The Universal Approximation Theorem states, in simplified terms, that a feedforward neural network with a suitable nonlinear activation and enough hidden units can approximate a broad class of continuous functions on a bounded domain to a desired level of accuracy, under the theorem's assumptions.

What does this mean intuitively?

A network can combine many simple nonlinear transformations to represent complicated input-output relationships. For example, a sufficiently capable network may approximate a curved relationship that a single straight line cannot represent.

What does the theorem not guarantee?

  • It does not guarantee that training will find the right parameters.
  • It does not guarantee that the network will generalize to unseen data.
  • It does not mean that every problem needs a very large network.
  • It does not say that adding more layers always improves performance.

The theorem concerns representational capacity. Successful training also depends on data, architecture, initialization, optimization and other practical choices.

3. Forward pass and layer calculations

A forward pass calculates a network's output for a given input. Each layer takes the previous layer's activations, calculates a weighted sum, adds a bias and applies an activation function.

\[ z^{(l)}=W^{(l)}h^{(l-1)}+b^{(l)} \] \[ h^{(l)}=\phi(z^{(l)}) \]

\(W^{(l)}\) is the weight matrix, \(b^{(l)}\) is the bias vector, \(h^{(l-1)}\) is the previous layer's output and \(\phi\) is the activation function.

Worked example: one neuron

Suppose \(x_1=2\), \(x_2=1\), \(w_1=0.5\), \(w_2=-1\), and \(b=0.2\).

\[ z=(0.5)(2)+(-1)(1)+0.2=0.2 \]

With ReLU, the output is \(\max(0,0.2)=0.2\). With sigmoid, the output is \(\sigma(0.2)\), approximately 0.55.

Dimensions matter

If a batch has \(B\) examples and each example has \(d\) features, its input shape is commonly \((B,d)\). A fully connected layer with \(m\) output neurons typically produces shape \((B,m)\). 

import torch
from torch import nn

x = torch.randn(32, 10)   # 32 examples, 10 features each
layer = nn.Linear(10, 4)
output = layer(x)

print(output.shape)       # torch.Size([32, 4])

Always check the dimensions when tracing a network. The number of input features to a layer must match the layer's expected input size.

4. Loss functions: measuring prediction error

A loss function converts predictions and targets into a numerical value that the training algorithm attempts to reduce. The suitable loss depends on the task and the format of the model output.

Mean squared error (MSE)

\[ \operatorname{MSE}= \frac{1}{N}\sum_{i=1}^{N}(y_i-\hat{y}_i)^2 \]

MSE is commonly used for regression. It averages squared differences between numerical targets and predictions.

Example: actual values are [10, 20] and predictions are [8, 18]. The squared errors are 4 and 4, so the MSE is \((4+4)/2=4\).

Binary cross-entropy (BCE)

\[ L=-[y\log(p)+(1-y)\log(1-p)] \]

BCE is commonly used for binary classification, where the target is 0 or 1 and the model represents the probability of the positive class as \(p\). Confident incorrect predictions are penalized strongly.

Categorical cross-entropy

Categorical cross-entropy is used for multiclass classification. In a common setup, the model produces one score (logit) per class, and the target identifies the correct class.

\[ \operatorname{softmax}(z_i)= \frac{e^{z_i}}{\sum_j e^{z_j}} \]

Softmax converts class logits into values that sum to one and can be interpreted as class probabilities. In PyTorch, when using nn.CrossEntropyLoss, pass raw logits and integer class labels; do not apply softmax before the loss.

TaskCommon lossTypical output
RegressionMSENumerical prediction
Binary classificationBinary cross-entropyOne probability for the positive class
Multiclass classificationCategorical cross-entropyOne score per class
The loss is the objective used for learning. Accuracy is a metric that describes how often predictions match class labels; loss and accuracy measure different things.

5. Gradient descent and learning rate

Training aims to find parameter values that produce low loss. Gradient descent uses the loss gradient to choose a parameter update.

\[ \theta_{\text{new}}= \theta_{\text{old}}-\eta\nabla_\theta L \]

Here, \(\theta\) represents the model parameters, \(L\) is the loss, \(\nabla_\theta L\) is the gradient and \(\eta\) is the learning rate.

Numerical example

Suppose the current parameter is 2.0, its gradient is 0.5 and the learning rate is 0.1.

\[ \theta_{\text{new}}=2.0-(0.1)(0.5)=1.95 \]

If the gradient were negative, subtracting it would increase the parameter under this update rule.

What does the learning rate do?

  • Too high: updates may overshoot useful values or make training unstable.
  • Too low: training may progress very slowly.
  • Reasonable value: allows useful progress while keeping updates manageable.

Batch gradient descent, SGD and mini-batches

  • Batch gradient descent: uses the full training dataset for a gradient update.
  • Stochastic gradient descent (SGD): uses one example for an update in its strict definition.
  • Mini-batch gradient descent: uses a small batch of examples for each update.

Mini-batches are common in deep learning because they offer an effective balance between computation and frequent parameter updates. In many software libraries, an SGD optimizer is used with mini-batches.

6. Backpropagation and the chain rule

Backpropagation calculates how the loss changes with respect to the model's parameters. It uses the chain rule to propagate derivatives backward from the output through the computations that produced it.

The chain rule

If \(y=f(u)\) and \(u=g(x)\), then:

\[ \frac{dy}{dx}= \frac{dy}{du}\frac{du}{dx} \]

For a longer chain of operations, multiply the local derivatives along the path. This is the central idea behind calculating gradients in a multilayer network.

Simple scalar example

Let \(u=2x\), \(y=u^2\), and suppose \(x=3\).

\[ u=2(3)=6,\qquad y=6^2=36 \] \[ \frac{du}{dx}=2,\qquad \frac{dy}{du}=2u=12 \] \[ \frac{dy}{dx}=\frac{dy}{du}\frac{du}{dx}=12(2)=24 \]

The derivative tells us how sensitive the final value is to a small change in the original input at that point.

Backpropagation in a neural network

  1. Run the forward pass and calculate the loss.
  2. Calculate the loss derivative with respect to the output.
  3. Use the chain rule to calculate derivatives for earlier layers.
  4. Continue until gradients for the trainable parameters are obtained.
  5. Let the optimizer use these gradients to update the parameters.

Backpropagation calculates gradients; it does not itself perform the optimizer's parameter update. The distinction is important when reading code or tracing a numerical example.

Typical PyTorch training step

optimizer.zero_grad()  # clear old gradients
outputs = model(inputs)  # forward pass
loss = criterion(outputs, targets)
loss.backward()        # calculate gradients
optimizer.step()       # update parameters

7. XOR: why a hidden layer matters

XOR outputs 1 when its two binary inputs are different and 0 when they are the same.

Input \(x_1\)Input \(x_2\)XOR output
000
011
101
110

A single linear classifier creates one linear decision boundary. The XOR positives (0,1) and (1,0) cannot be separated from the negatives (0,0) and (1,1) using one straight line.

A network with a hidden layer and nonlinear activations can combine intermediate features to represent XOR. The hidden layer transforms the original inputs into a representation in which the final output can distinguish the classes.

Exam idea: if asked why one perceptron cannot solve XOR, explain that XOR is not linearly separable. Adding hidden units and nonlinear activation functions gives the network greater representational power.

8. Customer churn classification

Customer churn prediction is a binary classification problem. The goal is to predict whether a customer will leave a service, using information such as account details, usage, tenure or service history. The exact features depend on the dataset.

Typical workflow

  1. Load and inspect the dataset.
  2. Identify the target column and input features.
  3. Check missing values, duplicates, data types and target labels.
  4. Separate the input features from the target.
  5. Split the data into training and validation/test sets.
  6. Encode categorical features into a numerical representation.
  7. Scale numerical features when appropriate.
  8. Build a neural network and choose a suitable loss.
  9. Train on training data and monitor validation performance.

Preprocessing without data leakage

Fit preprocessing steps, such as a scaler, using only the training data. Then apply the fitted transformation to validation and test data. If validation/test statistics are used to fit the preprocessing, information from those sets leaks into the training process.

Example binary classifier with PyTorch

import torch
from torch import nn

class ChurnMLP(nn.Module):
    def __init__(self, input_features):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(input_features, 32),
            nn.ReLU(),
            nn.Linear(32, 16),
            nn.ReLU(),
            nn.Linear(16, 1)
        )

    def forward(self, x):
        return self.network(x)

model = ChurnMLP(input_features=10)

# Output is one logit per example.
# BCEWithLogitsLoss combines sigmoid and binary cross-entropy.
criterion = nn.BCEWithLogitsLoss()

The example assumes the inputs have already been converted into suitable numerical features. Replace 10 with the actual number of features after preprocessing. For binary classification with BCEWithLogitsLoss, provide raw logits and compatible floating-point targets; do not apply sigmoid before the loss.

The final prediction can be formed by applying sigmoid to the logits and comparing the resulting probability with a chosen threshold. A threshold of 0.5 is common, but the best threshold depends on the task and the costs of different errors.

9. Fashion-MNIST classification with an MLP

Fashion-MNIST is a dataset of grayscale clothing images belonging to 10 classes. Each image is 28 × 28 pixels. A simple multilayer perceptron can flatten each image into 784 input values and produce 10 output logits, one for each class.

Load the dataset

import torch
from torch import nn
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

transform = transforms.ToTensor()

train_data = datasets.FashionMNIST(
    root="data",
    train=True,
    download=True,
    transform=transform
)

test_data = datasets.FashionMNIST(
    root="data",
    train=False,
    download=True,
    transform=transform
)

train_loader = DataLoader(
    train_data,
    batch_size=64,
    shuffle=True
)

test_loader = DataLoader(
    test_data,
    batch_size=64,
    shuffle=False
)

ToTensor() converts each image into a tensor. The DataLoader groups examples into batches. Shuffling the training data changes the order of examples between epochs; the test loader is commonly kept unshuffled for predictable evaluation.

Build the MLP

class FashionMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.network = nn.Sequential(
            nn.Flatten(),
            nn.Linear(28 * 28, 128),
            nn.ReLU(),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, 10)
        )

    def forward(self, x):
        return self.network(x)

model = FashionMLP()

criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001
)

Flatten() changes each image from shape \((1,28,28)\) to a vector of length 784. The final layer returns 10 logits. Cross-entropy uses the correct class label to evaluate those logits.

Training loop

device = torch.device(
    "cuda" if torch.cuda.is_available() else "cpu"
)
model = model.to(device)

for epoch in range(5):
    model.train()
    total_loss = 0.0

    for images, labels in train_loader:
        images = images.to(device)
        labels = labels.to(device)

        optimizer.zero_grad()
        logits = model(images)
        loss = criterion(logits, labels)
        loss.backward()
        optimizer.step()

        total_loss += loss.item()

    average_loss = total_loss / len(train_loader)
    print(
        f"Epoch {epoch + 1}: "
        f"training loss = {average_loss:.4f}"
    )

Validation / evaluation loop

model.eval()
correct = 0
total = 0

with torch.no_grad():
    for images, labels in test_loader:
        images = images.to(device)
        labels = labels.to(device)

        logits = model(images)
        predictions = logits.argmax(dim=1)

        correct += (predictions == labels).sum().item()
        total += labels.size(0)

accuracy = correct / total
print(f"Test accuracy: {accuracy:.4f}")

model.eval() switches layers such as dropout and batch normalization into evaluation behaviour. torch.no_grad() disables gradient tracking for evaluation, saving memory and computation. Neither operation updates model parameters.

Shape checkpoints: a batch of 64 images has shape (64, 1, 28, 28); after flattening, it has shape (64, 784); the final layer produces (64, 10); the class labels have shape (64,).

10. Training, validation and generalization

Training data is used to calculate gradients and update model parameters. Validation data helps compare model choices and monitor generalization without using those examples for parameter updates. Test data is generally reserved for a final, less frequently used evaluation.

Overfitting and underfitting

Overfitting

The model performs well on training data but worse on validation data. Validation loss may rise while training loss continues to fall.

Possible responses: early stopping, regularization, dropout, a simpler model or more representative data.

Underfitting

The model performs poorly on both training and validation data.

Possible responses: a more capable model, improved features, more training or less excessive regularization.

How to interpret loss

  • Training loss decreasing is evidence that the model is fitting the training data.
  • Validation loss decreasing can indicate improving performance on unseen examples.
  • Training loss decreasing while validation loss rises can be a sign of overfitting.
  • Loss values should be interpreted alongside the task, metrics and data.

1. What does the Universal Approximation Theorem tell us?

Under suitable conditions, a network with enough hidden units and suitable nonlinear activations can approximate a broad class of continuous functions. It does not guarantee successful training.

2. What is the difference between forward pass and backpropagation?

The forward pass computes outputs and loss. Backpropagation calculates gradients of the loss with respect to parameters.

3. What does the optimizer do?

It uses the gradients to update the trainable parameters according to its update rule.

4. Which loss is commonly used for regression?

Mean squared error is a common choice for regression.

5. Why is cross-entropy used for classification?

It measures how well predicted class probabilities or logits align with the correct class labels, according to the chosen formulation.

6. What happens if the learning rate is too high?

Updates may overshoot useful parameter values and make training unstable or prevent it from converging.

7. Why can't a single linear classifier solve XOR?

The XOR classes are not linearly separable, so one straight decision boundary cannot separate the positive and negative examples.

8. Why fit a scaler only on training data?

To avoid data leakage. Validation and test data should not influence the preprocessing statistics learned from training data.

9. Why flatten a Fashion-MNIST image for an MLP?

A 28 × 28 image has 784 pixel values. Flattening converts each image into a vector of length 784, suitable for a fully connected input layer.

10. What is overfitting?

The model fits the training data well but generalizes poorly to unseen data. One possible sign is training loss falling while validation loss rises.

Final memory chain: forward pass → loss → backpropagation → gradients → optimizer update → repeat → validation.
