1. AI, machine learning and deep learning

Artificial Intelligence (AI) is the broad field of building systems that perform tasks associated with intelligent behaviour. Machine learning (ML) is a part of AI in which systems learn patterns from data rather than relying only on manually written rules. Deep learning is a part of ML that uses neural networks with multiple layers.

Relationship: Deep learning is a subset of machine learning, which is a subset of AI.

What does a neural network learn?

A neural network contains adjustable parameters, mainly weights and biases. During training, it uses examples to adjust these parameters so that its predictions become more useful for the task.

  • Input: information supplied to the model.
  • Prediction: the model's output.
  • Target: the expected answer in supervised learning.
  • Loss: a numerical measure of prediction error.
  • Training: the process of adjusting parameters to reduce loss.

2. The artificial neuron: weights, bias and output

An artificial neuron receives inputs, scales them by weights, adds a bias and applies an activation function.

\[ z = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b \] \[ a = \phi(z) \]
  • Input \(x_i\): one feature supplied to the neuron.
  • Weight \(w_i\): controls the contribution of an input.
  • Bias \(b\): an adjustable offset added to the weighted sum.
  • Pre-activation \(z\): the weighted sum after adding bias.
  • Activation \(\phi\): transforms the pre-activation into the neuron's output.

Worked example

Suppose \(x_1=2\), \(x_2=3\), \(w_1=0.5\), \(w_2=-1\), and \(b=1\).

\[ z = (0.5)(2) + (-1)(3) + 1 = -1 \]

The final output depends on the activation function. With ReLU, \(a=\max(0,-1)=0\). Without an activation, the output would be \(z=-1\).

Counting trainable parameters

A fully connected layer with \(n\) input features and \(m\) neurons has \(n \times m\) weights and \(m\) biases.

\[ \text{Parameters} = nm + m = m(n+1) \]

Example: a layer with 10 inputs and 4 neurons has \(10 \times 4 + 4 = 44\) trainable parameters. 

import torch.nn as nn

layer = nn.Linear(10, 4)
print(sum(p.numel() for p in layer.parameters()))  # 44

3. McCulloch–Pitts neuron and perceptron

The McCulloch–Pitts neuron is a simplified binary model. It applies a threshold rule to its inputs. A perceptron is a related model that uses weighted inputs and a threshold decision.

\[ y = \begin{cases} 1, & \text{if } z \geq \theta \\ 0, & \text{otherwise} \end{cases} \]

The threshold \(\theta\) determines when the neuron activates. In a modern neuron, the threshold behaviour is often represented through weights, bias and an activation function.

Important limitation

A single perceptron creates a linear decision boundary. It cannot correctly represent every possible classification pattern. XOR is a standard example because its classes cannot be separated by one straight line.

4. Neural-network architecture and feedforward networks

A feedforward network passes information from input to output without sending the output of a later layer back to an earlier layer.

  • Input layer: receives the features.
  • Hidden layers: transform the representation of the input.
  • Output layer: produces the prediction.

For a layer \(l\), the computation is commonly written as:

\[ z^{(l)} = W^{(l)}h^{(l-1)} + b^{(l)} \] \[ h^{(l)} = \phi^{(l)}(z^{(l)}) \]

Here, \(h^{(l-1)}\) is the previous layer's output. The network applies this calculation layer by layer until it produces the final prediction.

Why use multiple layers?

Hidden layers can learn intermediate representations. Nonlinear activation functions allow the network to model nonlinear relationships. If every layer were purely linear, stacking those layers would still produce an overall linear transformation.

Universal approximation — an initial intuition

Under suitable conditions, a feedforward network with a suitable nonlinear activation and enough hidden units can approximate a broad class of continuous functions. This is a statement about representation capacity; it does not guarantee that training will find the desired parameters or that the model will generalize well.

5. Activation functions

The activation function transforms a neuron's weighted sum. Nonlinear activations allow a network to learn nonlinear patterns.

Sigmoid

\[ \sigma(z)=\frac{1}{1+e^{-z}} \]

Sigmoid maps real-valued inputs to values between 0 and 1. It is useful for representing a binary probability in an appropriate output setup. Very large positive or negative inputs can lead to small gradients.

Tanh

\[ \tanh(z) \in (-1,1) \]

Tanh produces outputs between -1 and 1 and is centred around zero.

ReLU

\[ \operatorname{ReLU}(z)=\max(0,z) \]

ReLU returns zero for negative inputs and returns the input itself for positive inputs. It is commonly used in hidden layers.

Leaky ReLU

\[ \operatorname{LeakyReLU}(z)= \begin{cases} z, & z \geq 0 \\ \alpha z, & z < 0 \end{cases} \]

Leaky ReLU allows a small negative output instead of setting every negative input to zero.

6. PyTorch and tensors

A tensor is a multidimensional container for numerical data. A scalar has no dimensions, a vector has one dimension, a matrix has two, and higher-dimensional tensors can represent batches of images or other data.

ObjectExample shapeMeaning
Scalar()One value
Vector(3,)Three values
Matrix(2, 3)Two rows, three columns
Image batch(N, C, H, W)Batch, channels, height, width

Creating tensors

import torch

x = torch.tensor([2, 4, 6])
zeros = torch.zeros((2, 3))
ones = torch.ones((2, 3))
empty = torch.empty((2, 3))       # values are not initialized
sequence = torch.arange(0, 10, 2)
uniform = torch.rand((2, 3))      # uniform random values
normal = torch.randn((2, 3))      # standard normal values

print(x.shape)
print(x.dtype)

torch.tensor() creates a tensor from supplied values. zeros() and ones() initialize every value. empty() allocates memory without initializing the values, so do not assume it contains zeros.

Tensor operations

x = torch.tensor([[1., 2.], [3., 4.]])

print(x + 2)          # elementwise addition
print(x * 3)          # scalar multiplication
print(x.sum())        # sum of all elements
print(x.mean(dim=0))  # mean down rows, one value per column
print(x.T)            # transpose
print(x @ x)          # matrix multiplication

Elementwise multiplication is different from matrix multiplication. The @ operator performs matrix multiplication when the tensor dimensions are compatible.

Indexing, slicing and reshaping

x = torch.arange(12)
matrix = x.reshape(3, 4)

first_row = matrix[0]
first_column = matrix[:, 0]
submatrix = matrix[:2, 1:3]
flat = matrix.flatten()

print(matrix.shape)  # torch.Size([3, 4])

Reshaping changes the arrangement of values, not their total count. A tensor with 12 elements can be reshaped to (3, 4), (2, 6) or (4, 3), but not (5, 3).

In Python, indexing begins at zero. In matrix[:2, 1:3], the first slice selects rows 0 and 1, and the second selects columns 1 and 2.

NumPy integration

import numpy as np
import torch

array = np.array([1.0, 2.0, 3.0], dtype=np.float32)
tensor = torch.from_numpy(array)
array_again = tensor.numpy()

# For a tensor that tracks gradients:
safe_array = tensor.detach().cpu().numpy()

A CPU tensor created with torch.from_numpy() can share memory with the NumPy array. Changes to one may affect the other. A tensor requiring gradients should generally be detached before converting it to NumPy.

7. Environment setup, reproducibility and common errors

Installing and checking PyTorch

Use the official PyTorch installation selector to choose a suitable command for your operating system and hardware. 

import torch

print(torch.__version__)
print("CUDA available:", torch.cuda.is_available())

If importing PyTorch fails, check whether it was installed into the same Python environment used by your notebook or editor.

Reproducibility and random seeds

import random
import numpy as np
import torch

random.seed(42)
np.random.seed(42)
torch.manual_seed(42)

if torch.cuda.is_available():
    torch.cuda.manual_seed_all(42)

Random seeds help make random initialization and other random operations repeatable in the same setup. They do not guarantee identical results across every device, library version or operation.

CPU and GPU

device = torch.device(
    "cuda" if torch.cuda.is_available() else "cpu"
)

x = torch.tensor([1.0, 2.0]).to(device)
model = model.to(device)  # after defining model

The model and the tensors used with it must be on compatible devices. CUDA is commonly used for NVIDIA GPU acceleration when available.

Common errors and how to debug them

  • Shape mismatch: inspect .shape and check the dimensions required by the operation.
  • Wrong dtype: regression inputs and targets commonly use floating-point tensors; class-index labels for cross-entropy are typically integer class IDs.
  • Device mismatch: move both model and data to the same device.
  • Unexpected broadcasting: check whether tensor dimensions are automatically expanded during an operation.
  • Tensor-to-NumPy error: use tensor.detach().cpu().numpy() when gradients are being tracked.
  • Autograd in-place error: avoid modifying tensors in place when autograd needs their earlier values.

8. Linear regression and mean squared error

Linear regression predicts a numerical value using a linear relationship. A one-input model is:

\[\hat{y}=wx+b\]

If \(w=2\), \(x=3\) and \(b=1\), then \(\hat{y}=2(3)+1=7\). The model's weight and bias are learned from data.

Create and load data

import torch
from torch.utils.data import TensorDataset, DataLoader

X = torch.linspace(-3, 3, 100).reshape(-1, 1)
y = 2 * X + 1 + 0.2 * torch.randn_like(X)

dataset = TensorDataset(X, y)
loader = DataLoader(dataset, batch_size=16, shuffle=True)

A Dataset represents examples and their targets. A DataLoader groups examples into batches and can shuffle their order during training.

Visualize the data

import matplotlib.pyplot as plt

plt.scatter(X.numpy(), y.numpy(), s=18)
plt.xlabel("x")
plt.ylabel("y")
plt.title("Synthetic data for linear regression")
plt.show()

Visualizing the data helps identify trends, outliers and whether a straight-line model is a reasonable starting point.

Define the model

import torch.nn as nn

model = nn.Linear(in_features=1, out_features=1)
predictions = model(X)

nn.Linear(1, 1) contains one weight and one bias and implements an affine transformation.

Mean squared error (MSE)

\[ \operatorname{MSE} = \frac{1}{N}\sum_{i=1}^{N}(y_i-\hat{y}_i)^2 \]

MSE averages squared differences between the true targets and the predictions. Squaring makes errors non-negative and gives larger errors more influence. 

def mse_loss(y_pred, y_true):
    return ((y_pred - y_true) ** 2).mean()

Predictions and targets must have compatible shapes. Accidental broadcasting can produce a loss that does not represent the intended comparison.

9. How a neural network learns

Training repeatedly uses the predictions and errors to improve model parameters. A typical training step has these parts:

  1. Forward pass: compute predictions from the inputs.
  2. Loss: compare predictions with the targets.
  3. Zero gradients: clear gradients left by the previous update.
  4. Backpropagation: calculate gradients of the loss with respect to parameters.
  5. Optimizer step: update the parameters using the gradients.
\[ \theta \leftarrow \theta - \eta\nabla_\theta L \]
  • \(\theta\) represents parameters such as weights and biases.
  • \(\eta\) is the learning rate.
  • \(L\) is the loss.
  • \(\nabla_\theta L\) is the gradient of loss with respect to the parameters.

Gradient descent subtracts the gradient because the gradient locally points toward increasing loss. The learning rate controls the size of the update.

A complete linear-regression training loop

import torch
import torch.nn as nn
from torch.utils.data import TensorDataset, DataLoader

X = torch.linspace(-3, 3, 100).reshape(-1, 1)
y = 2 * X + 1 + 0.2 * torch.randn_like(X)

loader = DataLoader(
    TensorDataset(X, y),
    batch_size=16,
    shuffle=True
)

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = nn.Linear(1, 1).to(device)
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

def mse_loss(y_pred, y_true):
    return ((y_pred - y_true) ** 2).mean()

for epoch in range(100):
    model.train()
    total_loss = 0.0

    for xb, yb in loader:
        xb, yb = xb.to(device), yb.to(device)

        optimizer.zero_grad()
        predictions = model(xb)
        loss = mse_loss(predictions, yb)
        loss.backward()
        optimizer.step()

        total_loss += loss.item()

    if (epoch + 1) % 10 == 0:
        print(
            f"Epoch {epoch + 1}, "
            f"loss = {total_loss / len(loader):.4f}"
        )

Important training terms

  • Epoch: one complete pass through the training dataset.
  • Batch: a subset of examples processed together.
  • Learning rate: controls the size of parameter updates.
  • Optimizer: uses gradients to update parameters.
  • Initialization: provides starting values for weights and biases.
  • Loss monitoring: helps reveal whether training is progressing.

A learning rate that is too high may make training unstable; one that is too low may make training slow. Mini-batches balance computational efficiency with frequent parameter updates.

10. Saving and loading a trained model

Model serialization stores learned parameters so that they can be reused later. For a PyTorch model, a common approach is to save its state dictionary. 

# Save learned parameters
torch.save(model.state_dict(), "model_weights.pth")

# Recreate the same architecture before loading
loaded_model = nn.Linear(1, 1)
loaded_model.load_state_dict(
    torch.load("model_weights.pth", map_location="cpu")
)
loaded_model.eval()

The architecture used for loading must match the architecture used when saving. eval() switches the model to evaluation mode; it does not itself calculate predictions.

11. Practical habits for successful deep learning

  • Check tensor shape, dtype and device when debugging.
  • Set random seeds when comparing experiments.
  • Choose initialization and learning rates thoughtfully.
  • Shuffle training data when appropriate.
  • Track loss rather than assuming the model is learning.
  • Keep training and evaluation data separate when measuring generalization.
  • Save model parameters and document important settings.
