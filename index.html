CONTEXT

Before neural networks: from machine learning to deep learning

To understand why neural networks were developed, first consider the general problem: we have examples and want a computer to learn a rule that works on new examples.

Artificial intelligence, machine learning, and deep learning

  • Artificial intelligence (AI): the broad field of building systems that perform tasks associated with intelligence.
  • Machine learning (ML): a part of AI in which a system learns patterns from examples instead of relying only on rules written by a programmer.
  • Deep learning (DL): a part of ML that uses neural networks with multiple processing layers to learn useful representations from data.
  • Generative AI: AI that creates new content, such as text, images, audio, or code. It uses many of the deep-learning ideas introduced later in this course.

For example, a hand-written rule-based spam filter might search for a fixed list of suspicious words. A machine-learning spam filter learns associations from labelled spam and non-spam messages. A deep-learning system can learn more complex patterns from text, sometimes with less manual feature design.

Traditional machine learning and feature engineering

A feature is a measurable input used by a model, such as house area, number of rooms, or a pixel value. Feature engineering means humans choose or construct useful inputs before model training. In traditional workflows, domain experts may need to design these features carefully.

ApproachTypical ideaStrength / limitation
Linear modelsLearn a weighted combination of featuresFast and interpretable, but limited for complex patterns
Tree-based modelsLearn a sequence of if/then splitsPowerful for structured/tabular data
Deep learningLearn layers of representations from dataUseful for complex images, audio, text, and other high-dimensional inputs; often needs more data and computation

Traditional ML can struggle when raw inputs are very large, such as every pixel in an image, because manually designing the right features is difficult. Deep learning can learn simple features first and combine them into more complex features in later layers. This is called representation learning.

Connection to the next topic: A neural network is a function that transforms input features into an output. The next sections build this function from its smallest component: a neuron.
