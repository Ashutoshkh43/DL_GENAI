# BSDA2001 — Deep Learning and Generative AI Notes

A static study-notes website with an introduction and separate pages for Weeks 1–4.

## Files
- `index.html` — introduction and learning roadmap
- `week1.html` — ANN foundations, PyTorch tensors, XOR and Fashion-MNIST workflow
- `week2.html` — forward/backpropagation, optimisation, churn prediction and classification practice
- `week3.html` — CNN fundamentals, convolution/pooling, model training and shape calculations
- `week4.html` — transfer learning, pretrained EfficientNet, fine-tuning and U-Net segmentation
- `styles.css` — shared styling
- `script.js` — table-of-contents highlighting and smooth navigation
- `SOURCE_INVENTORY.md` — source files used and accuracy notes

## Run locally
Extract the ZIP and open `index.html` in a browser. MathJax is loaded from a CDN for equations, so an internet connection is needed to render mathematical notation.

## Publish on GitHub Pages
Upload all site files to the same repository folder, commit them, then enable GitHub Pages in the repository settings. Keep the filenames and relative paths unchanged.

## Course source notes
The pages have been expanded using the uploaded lecture slide and live-coding archives. They explain and extend the supplied materials rather than transcribing them word-for-word. The Week 4 practice questions are additional revision questions, not claimed to be official graded-assignment questions. See `SOURCE_INVENTORY.md` for the materials used.
