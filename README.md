# BSDA2001 — Deep Learning and Generative AI Notes

A small static website with an introduction and separate pages for Weeks 1–4.

## Files
- `index.html` — introduction and learning roadmap
- `week1.html` — Week 1 foundations
- `week2.html` — Week 2 implementation and practice
- `week3.html` — Week 3 CNN notes and practice
- `week4.html` — Week 4 source availability status
- `styles.css` — shared styling
- `script.js` — table-of-contents scroll highlighting and smooth navigation
- `SOURCE_INVENTORY.md` — source inventory and Drive access limitations

## Run locally
Open `index.html` in a browser. MathJax is loaded from a CDN for equations, so an internet connection is needed to render mathematical notation.

## Publish on GitHub Pages
Upload all site files to the same repository folder, commit them, then enable GitHub Pages in the repository settings. Keep the filenames and relative paths unchanged.
